# Bird Game

A Flappy Bird-style browser game built with HTML5 Canvas and vanilla JavaScript.

## Play

Open `index.html` in any modern browser — no build step or server required.

## Controls

- **Click** or **Tap** to flap
- **Spacebar** to flap (desktop)

## Features

- Smooth 60fps animation with `requestAnimationFrame`
- Responsive canvas that adapts to any screen size
- Increasing difficulty — pipes speed up every 5 points
- In-memory high score tracking
- Works on desktop and mobile
- Zero external dependencies

## Tech Stack

- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- CSS3
